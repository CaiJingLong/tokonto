# 实现与验收

目标：本地、可插件化、AI 优先的 token 用量与分时计费工具。

- [x] 统一用量协议、精确十进制计费、时区与历史价格
- [x] SQLite 持久化、去重、价格快照、重算预览、分时聚合
- [x] Codex / Claude Code / OMP / WorkBuddy / Cherry Studio 采集
- [x] 外置脚本 Provider 协议、独立进程执行、超时和失败诊断（可信脚本，非沙箱）
- [x] 完整 CLI 命令发现、JSON Schema、非交互管理和 Skill
- [x] 本地 server、dashboard、筛选、图表、来源状态
- [x] 边界测试、CLI 集成测试、浏览器验收、独立代码评审

约定：token 分类互斥；reasoning 为 output 子集；时间范围左闭右开；时段按规则时区，跨午夜以起始日决定星期；缺价明确 unknown；不同币种分别汇总；上报费用不冒充实际账单；不保存对话正文。新价格规则不静默修改已入库费用，显式 reprice 才更新快照并记录审计。价格规则按 priority 唯一选择，不叠乘优惠，同级冲突不猜测。

## 验证记录（2026-09-18）

- Bun 自动化测试覆盖定价、时区/DST、历史修订、五种解析器、跨文件去重、脚本超时及子进程、CLI、HTTP 来源隔离、统计索引和筛选；具体数量以当前 `bun test` 为准。
- TypeScript 检查与 dist 构建通过；构建目录独立启动验证通过。
- Edge 实际交互：来源筛选、价格新增/停用、用量费用解释；390px 手机布局无横向页面溢出，空状态可用，浏览器控制台无报错。
- 脚本示例注册、测试、连续两次采集通过，第二次 inserted=0；Skill 安装到隔离临时目录与 quick_validate 校验通过。
- 五个内置来源已对本机真实日志/SQLite 进行只读采集验证；不将私人日志或账本纳入仓库。源日志自身的矛盾计数保留诊断，不猜测修正。
- 独立只读评审发现的 5 项重要问题均已修复并有回归验证。

边界：官方价格是有核验日期的有限快照；已知模型在没有匹配手动规则时按预设估算，订阅和代理的估算不等同账单；未知模型需配置价格。WorkBuddy 聚合无法可靠拆分多模型或跨计费时段；旧 Cherry IndexedDB 与 ZIP 不直接读取。Windows/Linux 来源日志尚未实机验收。
