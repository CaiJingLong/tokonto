# Tokonto 0.2.0

## 中文

本次更新带来简体中文与英文面板。右上角切换语言，浏览器会记住选择；首次访问跟随浏览器语言，不支持时回退英文。导航、统计图表、明细、来源与价格表单、重算预览和操作提示均支持两种语言。语言切换保留当前筛选、时区与币种，不改变用量及已存费用。

新增完整 [English README](https://github.com/CaiJingLong/tokonto/blob/v0.2.0/README.en.md) 与双语本地化指南，今后的 README 和 Release 按双语维护。GitHub 归档与 npm 包均包含两份 README。CLI/API 字段、模型标识、CSV 表头及原始技术诊断保持原值，兼容已有 AI 工作流。

**安装 / 升级**（需要 Bun ≥ 1.3.14 且已加入 PATH）：

```sh
bun install --global tokonto@0.2.0
# 或 npm install --global tokonto@0.2.0
tokonto server --open
```

升级前停止服务并备份 `tokonto doctor --json` 显示的完整数据目录。已有配置与计费快照保留，无须数据迁移。

归档安装：下载本 Release 的 `tokonto-0.2.0.tar.gz` 与 `SHA256SUMS` 到同一目录，校验后解压运行：

```sh
shasum -a 256 -c SHA256SUMS # Linux: sha256sum -c SHA256SUMS
tar -xzf tokonto-0.2.0.tar.gz
cd tokonto-0.2.0
bun cli.js server --open
```

本版通过 GitHub Release 触发 npm Trusted Publishing（OIDC）。npm 发布为异步任务，可在仓库 Actions 查看进度。MIT 许可证；仍需要 Bun，不是独立原生程序。

## English

This release adds Simplified Chinese and English to the dashboard. Choose a language in the top bar; the browser remembers your selection. First visits follow the browser's supported language, falling back to English. Navigation, charts, activity, provider/pricing forms, repricing previews and operation messages support both languages. Switching preserves filters, time zone and currency without changing usage or saved costs.

A complete [English README](https://github.com/CaiJingLong/tokonto/blob/v0.2.0/README.en.md) and bilingual localization guide are included. Future READMEs and releases are maintained in both languages, and both installation formats include both READMEs. CLI/API fields, model identifiers, CSV headers and original technical diagnostics retain their values for compatibility with existing AI workflows.

**Install / upgrade** (requires Bun ≥ 1.3.14 on PATH):

```sh
bun install --global tokonto@0.2.0
# Or: npm install --global tokonto@0.2.0
tokonto server --open
```

Before upgrading, stop the server and back up the entire data directory reported by `tokonto doctor --json`. Existing configuration and pricing snapshots are preserved; no data migration is needed.

For archive installation, download `tokonto-0.2.0.tar.gz` and `SHA256SUMS` from this release into the same directory:

```sh
shasum -a 256 -c SHA256SUMS # Linux: sha256sum -c SHA256SUMS
tar -xzf tokonto-0.2.0.tar.gz
cd tokonto-0.2.0
bun cli.js server --open
```

Publishing this GitHub Release triggers npm Trusted Publishing via OIDC. npm publishing is asynchronous; follow its progress in Actions. Licensed under MIT. Bun is still required; this is not a standalone native executable.
