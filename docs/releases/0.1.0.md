# Tokonto 0.1.0

本地查看多个 AI 工具的 token 用量与估算费用，用 CLI 和 AI Skill 管理来源、价格和分时统计。

**Tokonto** 的名字来自 **Token + Konto（德语：账户）**，意为“你的 AI 用量账本”。项目名为 Tokonto，包名和命令名为 `tokonto`。

支持 Codex、Claude Code、OMP、WorkBuddy、Cherry Studio，并可通过脚本接入自己的 agent。Dashboard 提供趋势、来源分布、模型排行和计费明细。手动规则优先，无匹配时使用内置模型参考价格；支持峰谷时段、优惠日期、时区和上下文阈值，保留计费快照及重算审计。

## 安装

先安装 Bun ≥ 1.3.14，并将其加入 PATH，再从 npm 安装：

```sh
bun install --global tokonto
tokonto server --open
```

也支持 `npm install --global tokonto`，运行仍需 Bun。以下是 GitHub Release 的归档安装方式。

需要 **Bun 1.3.14 或更高版本**。下载本 Release 的 `tokonto-0.1.0.tar.gz` 和 `SHA256SUMS`，放在同一目录：

```sh
# macOS；Linux 可用 sha256sum -c SHA256SUMS
shasum -a 256 -c SHA256SUMS
tar -xzf tokonto-0.1.0.tar.gz
cd tokonto-0.1.0
bun cli.js --version
bun cli.js server --open
```

打开 http://127.0.0.1:4318。默认自动发现来源，每 60 秒同步；`--interval 0` 关闭自动采集。可执行 `bun link` 将 CLI 链接为 `tokonto`，或一直使用 `bun /安装目录/cli.js`。无须安装项目依赖；此包不是独立原生可执行文件。

安装包内含完整 README、Provider 示例、价格说明与 AI Skill。通过 `bun cli.js skill install --target ~/.codex/skills --json` 安装 Skill，目录已存在时不会覆盖。

## 数据与兼容性

- 新安装默认保存在 `~/.tokonto`；旧名 `token-usage` 的已有账本可原地继续使用，兼容 `TOKEN_USAGE_HOME`，新变量为 `TOKONTO_HOME`。用 `tokonto doctor --json` 确认实际目录。数据不会上传到云端，不保存聊天正文或 API key。
- 已有用户升级前应停止服务并备份整个数据目录。新价格不会静默修改已存费用。
- 本地已验证 macOS；Linux 的自动验证由仓库 CI 执行。第三方应用的 Windows/Linux 实际日志路径尚未实机验收。
- 内置价格为 2026-09-18 的有限快照，订阅或代理按标准 API 价估算，未知模型仍为未定价。WorkBuddy 聚合无法精确拆分多模型、跨时段调用；Cherry 旧 IndexedDB、ZIP 不直接读取。
- 插件以当前用户权限执行，只运行可信脚本；服务仅绑定本机回环地址，不提供远程多用户认证。
